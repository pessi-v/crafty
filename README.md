# Crafty

## A home cookbook with a Craft CMS backend and a Three.js animation

I did this project in order to learn Craft CMS. I thought of a unique interface, which might not be the most practical or accessible, but at least it's entertaining.

Features:

- Recipes as Craft CMS entries
- Recipes can be submitted with a form from the frontend
- Recipes have tags and tags can be used to show subsets of recipes
- Live search for recipes with matching for titles and text content
- Navigation happens in modals
- Modals have navigation buttons (back/forward)
- Also browser navigation buttons correctly move back and forth in the modal history
- Custom cursor
- A radio widget, modeled as a Global element that can be toggled on/off from the Craft CMS admin
- Radio widget streams 2 online radio channels (NTS Radio)
- An SVG hamburger menu with a neat hover effect
- Actual recipes that I like to cook
- Vite, Postcss & Tailwindcss in the backend
- Self-hosted Craft CMS
